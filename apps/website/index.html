DEVELOPMENT
USE↗
a.

Your application

pnpm add -D @ainotation/vite@beta
vite.config.ts 
import { ainotation } from '@ainotation/vite';

export default {
  plugins: [ainotation({ name: 'my-app' })],
};

Keep your existing plugins. The SDK is included. Open your development app and look for the floating Ainotation icon.

b.

Your coding agent

MCP client configuration 
{
  "mcpServers": {
    "ainotation": {
      "command": "npx",
      "args": ["--yes", "@ainotation/mcp@beta", "connect"]
    }
  }
}

Your client should share workspace roots. Otherwise, append --directory and your project path.

Read the setup guide ↗

A few things to keep in mind

i.

Local by default.

Feedback lives in your browser, organized by project and page. No account or cloud setup. MCP is optional.

ii.

For the workbench.

The Vite plugin runs in development. Your production build stays free of the inspector. Screen capture asks for your permission.

iii.

Free to develop with.

Internal development is free, including commercial projects. Commercial distribution, hosted services and production integration require authorization.
